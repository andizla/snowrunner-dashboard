# Changelog

## 1.0.0

- **The first release.** `NextGenTuning.asi` adds a tab "Tuning" to the NEXT GEN menu, opened and closed with F1. It draws the figures that Next Gen Gameplay and Next Gen Tire Inflation publish: sliders, switches, buttons and lines to read, under each mod's name and its own group headings, with one Reset a group. A moved slider acts at once, and the mod saves it in its own ini. The key is saved in `NextGenTuning.ini`, which the first start writes with the defaults. `NextGenTuning.log` has one line for each change made on the tab. The tool hooks nothing of the game and reads none of its memory.
